# @oidc-exchange/linux-arm64-gnu

The **Linux arm64 (glibc)** native binary for [`@oidc-exchange/node`](https://www.npmjs.com/package/@oidc-exchange/node).

It is installed automatically as an `optionalDependency` of `@oidc-exchange/node` on this platform. **Don't install it directly** — install [`@oidc-exchange/node`](https://www.npmjs.com/package/@oidc-exchange/node) instead.
